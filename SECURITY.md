# Security policy

## Scope

TIDEWATCH is an offline log-analysis utility. Security reports should focus on defects in its parser, correlation logic, data handling, or generated reports.

## Reporting a vulnerability

Please do not publish private logs, personal data, credentials, or a weaponized proof of concept in a public issue. Report the affected version, a minimal sanitized sample, expected behavior, and observed behavior through a private channel provided by the repository owner.

## Data handling

TIDEWATCH does not intentionally send data over the network. Input logs and generated reports may contain sensitive operational data; store, share, and redact them accordingly.
